# Agent 运行手册

## 服务降级

工具服务持续限流或不可用时，系统先停止写操作并降级为只读模式。若只读结果仍不足以安全完成任务，应转交人工处理，不得无限重试。

## 发布门禁

新的 Agent 版本在发布前必须通过固定任务集的离线评测，并保留与上一版本的对照报告。涉及外部发送或生产写入的变更还需要人工批准，发布方案必须包含可执行的回滚路径。

## 敏感数据

处理敏感数据时遵循最小权限原则。Trace、工具参数和报告写入前必须脱敏，同时保留必要的访问审计。密钥不得进入模型上下文或普通日志。

## 证据不足

当允许读取的资料不足以支持答案时，知识库 Agent 应明确拒答，并提示读者补充资料。系统不能依赖模型常识猜测内部事实。
